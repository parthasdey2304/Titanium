SiriOrbWidget PySide6

Authentic AmazingUI 3D Sphere video canvas running at 60 FPS. Features transparent frameless bounds, organic fluid animations, and docks permanently at the top-right.

TitaniumMusicPlayer COM / yt-dlp

Headless background audio streaming engine using native Windows Media Player COM (WMPlayer.OCX) with automatic audio ducking and zero external windows.

WakeWordListener DSP Filter

Always-on listener with a 4th-order Butterworth bandpass filter (300-3400 Hz) and crest-factor analysis that completely rejects typing clicks up to 90+ WPM.

CompactSubtitlePill Gemini Bubble

Displays user queries in a sleek Gemini dark-mode bubble shifted right (#131314) and AI responses with sparkle icon without window clutter.

AgentRouter Gemini Flash

Zero-latency local action dispatcher for desktop apps, folders, and settings, backed by Google Gemini 2.5 Flash Lite for sub-second Hinglish replies.

SingleInstanceLock Socket IPC

Port 48123 TCP IPC server ensuring strictly ONE running process in Task Manager and bringing the existing orb to front upon duplicate launch.
